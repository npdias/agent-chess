# Product

## Register

product

## Users

Agent builders running local tool-native chess agents against a reproducible Stockfish opponent. They watch matches on desktop during development, inspect compact agent activity, verify legal behavior, and occasionally check the same match from a narrow browser window.

## Product Purpose

Agent Chess proves that a local agent can play repeated legal turns through a compact tool interface while a person understands match state at a glance. Success means users can create a match, connect a local harness, identify side to move, read verified phase progress, inspect concise candidate summaries, and distinguish agent, connector, and system activity without reading protocol docs.

## Brand Personality

Calm, credible, focused. Board-first identity. Dense enough for technical observation, quiet enough that live match state remains dominant.

## Anti-references

No warped chessboard, oversized marketing layout, hidden live state, invented agent reasoning, decorative dashboard clutter, nested cards, neon AI styling, or phase progress without evidence. Avoid layouts that require routine desktop scrolling to keep board, phase, and activity visible together.

## Design Principles

1. Keep board geometry truthful and stable.
2. Show verified state before secondary controls.
3. Distinguish agent decisions from connector and system events.
4. Fit core live-match workflow into one desktop viewport.
5. Preserve progressive detail without overwhelming first use.

## Accessibility & Inclusion

Keep keyboard focus visible, labels explicit, status updates available through `aria-live`, color-independent phase states, readable contrast, square board geometry, responsive ordering, and reduced-motion support. Support 320px minimum width without horizontal overflow.
