# Writing Style

Maintained comments and documentation follow ASD-STE100 Issue 9 rules.

This project does not claim formal dictionary certification.

## Rules

Use approved words when possible.

Use one approved meaning for each word.

Use active voice.

Use American spelling.

Write one instruction in each procedural sentence.

Keep procedural sentences at 20 words or fewer.

Keep descriptive sentences at 25 words or fewer.

Keep one topic in each paragraph.

Keep each paragraph at six sentences or fewer.

Use consistent technical nouns and verbs.

## Technical Terms

Approved project terms include Agent Chess, FEN, PGN, UCI, WebSocket, MCP, Node.js, Stockfish, GitHub, and API.

Define a new technical term at its first important use.

Use **Agent Chess** as the project, product, service, and repository name.

Do not use **Chess Bench** as a public name.

## Exceptions

Keep legal text verbatim.

Keep code, commands, identifiers, protocol fields, and exact error messages unchanged.

Do not rewrite quoted third-party text.

## Review

1. Check sentence length.

2. Check active voice.

3. Remove ambiguous words.

4. Check each procedure for one action.

5. Check technical term consistency.
